# CS 361 – Software Engineering

This repository contains coursework, programming challenges, technical documentation, and projects related to software engineering.

## Course Assignments

### In-Class Challenges

- **Challenge 4.1 – Mermaid Diagramming**
  - Created flowcharts using Mermaid syntax.
  - Demonstrated system components, communication paths, and subgraphs.
  - [View Mermaid Diagrams](https://github.com/garcbenn/CS361-Software-Engineering/blob/main/In-Class-Challenges/challenge4-1.md)

- **Challenge 4.2 – Wrap a File API**
  - Developed a Python class that wraps a fictional file-handling API.
  - Implemented a constructor and methods for reading, writing, and closing files.
  - Demonstrated object-oriented programming concepts, including encapsulation, methods, and instance variables.
  - [View Python File Wrapper](https://github.com/garcbenn/CS361-Software-Engineering/blob/main/In-Class-Challenges/file_wrapper.py)

### Project 2 – Functional Specification

- Developed functional requirements and specifications for the Bend Bike Shop bicycle rental system.
- Documented customer, employee, and manager interactions.
- Identified system functionality, constraints, and expected behaviors.

### Project 3 – UX Flows, Wireframes, and Prototypes

- Created UX flow diagrams for customer, employee, and manager scenarios.
- Designed low-fidelity wireframes for the bicycle rental application.
- Developed an interactive bicycle rental prototype using HTML, CSS, and JavaScript.
- Hosted the prototype using GitHub Pages.

### Project 4 – Technical Design Document

- Developed a technical design document for the Bend Bike Shop bicycle rental system.
- Identified system actors, goals, non-goals, constraints, assumptions, and measurable non-functional requirements.
- Created a Mermaid component diagram showing the relationships between the application's major components.
- Used AI to identify and evaluate six potential design issues.
- Revised the original technical design based on the approved recommendations.
- Used AI to expand the technical design with additional details about system workflows, database structure, security, error handling, and testing.
- Evaluated three AI-generated design additions and documented my reasoning.

**Project 4 Documents:**

- [Technical Design Document](Project-4-Technical-Design-Doc/design_doc.md) – Original technical design with approved corrections.
- [AI Issues Report](Project-4-Technical-Design-Doc/design_doc_issues_ai.md) – Six issues identified during the AI review.
- [AI-Expanded Technical Design](Project-4-Technical-Design-Doc/design_doc_ai.md) – Expanded technical design generated with AI assistance.
- [AI Design Critique](Project-4-Technical-Design-Doc/design_doc_critique.md) – My evaluation of three AI-generated design recommendations.

## Purpose

This repository documents my progress in software engineering, including requirements gathering, functional specifications, user experience design, object-oriented programming, software architecture, technical documentation, and software prototyping.

The Bend Bike Shop projects demonstrate the process of developing a software system from initial requirements through user interface design and technical planning. They also demonstrate how AI can assist with software design while keeping final design decisions under human review.

# CS 361 – Software Engineering

This repository contains coursework, programming challenges, technical documentation, and projects related to software engineering.

## Course Assignments

### In-Class Challenges

- **Challenge 4.1 – Mermaid Diagramming**
  - Created flowcharts using Mermaid syntax.
  - Demonstrated system components, communication paths, and subgraphs.
  - [View Mermaid Diagrams](https://github.com/garcbenn/CS361-Software-Engineering/blob/main/In-Class-Challenges/challenge4-1.md)

- **Challenge 4.2 – Wrap a File API**
  - Developed a Python class that wraps a fictional file-handling API.
  - Implemented a constructor and methods for reading, writing, and closing files.
  - Demonstrated object-oriented programming concepts, including encapsulation, methods, and instance variables.
  - [View Python File Wrapper](https://github.com/garcbenn/CS361-Software-Engineering/blob/main/In-Class-Challenges/file_wrapper.py)

### Project 2 – Functional Specification

- Developed functional requirements and specifications for a bike rental system.
- Documented user interactions and system functionality.

### Project 3 – UX Flows, Wireframes, and Prototypes

- Created UX flow diagrams for customer, employee, and manager scenarios.
- Designed low-fidelity wireframes.
- Developed an interactive bike rental prototype using HTML, CSS, and JavaScript.

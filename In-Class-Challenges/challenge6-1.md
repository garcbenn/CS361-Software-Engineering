# In-Class Challenge 6.1: Work Breakdown Structure

## Online Pizza Ordering System (100%)

**1. User Interface (20%)**
  - Create the homepage
    - Design the navigation menu
    - Add links to the pizza menu and shopping cart
  - Create the pizza menu page
    - Display available pizzas with descriptions and prices
    - Allow customers to select pizza sizes and toppings
  - Create the checkout page
    - Display the order summary
    - Add customer information and payment fields

**2. User Accounts (15%)**
  - Implement user registration
    - Create a registration form
    - Validate user information
  - Implement user login
    - Create a login form
    - Verify user credentials
  - Manage customer profiles
    - Allow customers to update their information
    - Save delivery addresses

**3. Pizza Ordering System (25%)**
  - Implement pizza customization
    - Allow customers to choose pizza sizes
    - Allow customers to add or remove toppings
  - Implement shopping cart functionality
    - Add and remove pizzas from the cart
    - Calculate the total order price
  - Implement order processing
    - Validate orders before submission
    - Generate an order confirmation

**4. Payment Processing (15%)**
  - Integrate a payment service
    - Connect to a third-party payment provider
    - Handle successful and failed payments
  - Implement payment confirmation
    - Update the order payment status
    - Display a payment confirmation to the customer

**5. Database and Backend (15%)**
  - Design the database
    - Create tables for customers, pizzas, and orders
    - Define relationships between tables
  - Implement backend functionality
    - Create API endpoints for retrieving pizza information
    - Create API endpoints for submitting orders
  - Manage order records
    - Save completed orders
    - Retrieve customer order history

**6. Testing and Deployment (10%)**
  - Test website functionality
    - Test registration and login
    - Test pizza customization and checkout
  - Test payment and order processing
    - Verify correct order totals
    - Test failed payment handling
  - Deploy the website
    - Configure the hosting environment
    - Deploy and verify the working website
